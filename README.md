# 無料計算ツール集

「表示価格だけでは分からない本当の金額」と「ゲーム・仕事の数字の換算」を、その場で計算できる無料ツール集です。登録は不要で、すべての計算はブラウザ内で行われ、入力内容は外部に送信されません。光回線・格安SIMの実質月額比較から、FPS感度、消費税、手取りまで、暮らしと仕事の計算を幅広く揃えています。

## 🌐 ライブサイト

**[https://ikesita.github.io/free-tools-site/](https://ikesita.github.io/free-tools-site/)**

## 主なツール

- **通信**：光回線 実質月額計算機、格安SIM 実質月額計算機、ダウンロード時間計算機
- **ゲーム**：FPS感度コンバーター、FOV変換ツール、モニターサイズ／PPI計算機
- **お金・仕事**：消費税計算機、手取り計算機、ローン返済試算、ライター実質時給計算機、時給・月収・年収換算
- **日常・便利**：文字数カウント、QRコード作成、単位換算、パーセント計算機、日数・時間計算機
- **健康**：BMI計算機、基礎代謝・消費カロリー計算機、歩数・睡眠・ランニングペース計算機
- **解説ガイド**：複利・積立、体脂肪率、営業日計算、割り勘、燃費など

## 使い方

ブラウザでライブサイトを開き、使いたいツールを選ぶだけです。インストールや会員登録は不要です。

## 注意事項

計算結果はあくまで目安です。正式な金額や条件は、各サービスの公式情報でご確認ください。
